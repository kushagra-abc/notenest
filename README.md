# iNotebook - Cloud Notebook on MERN Stack

iNotebook is a full-stack web application designed for users to securely store and access their notes on the cloud.

## Features
- **User Authentication:** Secure signup and login using JWT (JSON Web Tokens).
- **CRUD Operations:** Create, Read, Update, and Delete notes seamlessly.
- **State Management:** Built with React Context API for clean state handling.

## Tech Stack
- **Frontend:** React.js, HTML5, CSS3, Bootstrap
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
